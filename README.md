Расширение для Chrome, которое позволяет скрывать статьи про "Искусственный интеллект" из ленты habr.com.

Расширение в Chrome Web Store: https://chromewebstore.google.com/detail/ai-less-habr/ommpbndiakfdikdhigffognkjmdpiifb

Внимание: скрывается не контент, написанный ИИ (LLM), а контент про ИИ.

Есть следующие варианты:
- скрывать хаб "Искусственный интеллект"
- скрывать по словам в заголовке (настраиваемый список)
- скрывать по тегам (настраиваемый список)
- инвертированный режим (показать, попадающее под фильтры, и скрыть остальное)

По умолчанию включено только скрытие хаба "Искусственный интеллект".

Чтобы видеть счетчик скрытых статей, закрепите иконку расширения на панели инструментов через меню расширений (иконка паззла).
